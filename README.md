# Slow + Reverse MP3 (хуй)

Простая программа для Windows: замедляет mp3 и разворачивает его задом наперёд. Нужна для ремиксов: загружаешь получившийся файл в Suno, риверсишь обратно и просишь вернуть исходную скорость.

## Возможности

- Ползунок замедления от 0.20x до 2.00x (рекомендуется 0.80 или 0.70)
- Реверс трека задом наперёд
- Пакетная обработка: можно добавить сразу несколько mp3
- Вариант «тон падает вместе со скоростью» (как у пластинки) или с сохранением тона
- Готовые английские промпты для Suno под выбранную скорость, с кнопкой копирования
- Результат сохраняется рядом с оригиналом: `трек_0.80x_rev.mp3`

## Как пользоваться

1. Нажми «+ Добавить mp3» и выбери файлы.
2. Выбери замедление ползунком или кнопками 0.80 / 0.70.
3. Нажми «Обработать».
4. Загрузи полученный mp3 в Suno, сделай реверс обратно и вставь промпт из блока «Дальше в Suno».

## Установка

Скачай готовый `SlowReverse.exe` из раздела Actions (артефакт SlowReverse) или из Releases. Ничего устанавливать не нужно.

### Сборка самому

Запусти workflow **Build SlowReverse.exe** во вкладке Actions. Он сам скачает ffmpeg и соберёт exe через PyInstaller.

Локально: положи `ffmpeg.exe` рядом с `slow_reverse_gui.py` и выполни:

    pip install pyinstaller
    pyinstaller --onefile --noconsole --name SlowReverse --add-binary "ffmpeg.exe;." slow_reverse_gui.py

## Технологии

Python, Tkinter, ffmpeg, PyInstaller.
